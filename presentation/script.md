Presentation Script: How AI Coding Agents Are Changing Software Development

Target duration: 2:30–3:00
Speakers: Wumaier Kutelike and Sebastian Gonzalez

Wumaier

Hello, our names are Wumaier and Sebastian. Today, we will explain how AI coding agents are changing software development, including their practical uses, potential benefits, and risks.

On June 30, 2026, GitHub announced that Copilot Agent became available inside JetBrains AI Assistant. According to GitHub, developers can select Copilot from the agent picker, choose a supported model, and adjust the reasoning level. The agent can examine a project, propose changes, run commands, and work through multistep tasks.

For this presentation, an AI coding agent means an AI tool that uses project context and development tools to complete several steps toward a programming goal. It goes beyond simply suggesting the next line of code.

For example, a developer can ask an agent to fix a small bug. The agent may inspect the project, suggest a change, run relevant commands, and revise its work after receiving feedback. Agents may also help with refactoring, writing tests, and updating documentation.

These capabilities may reduce repetitive work, provide developers with a useful starting point, and reduce switching between tools. However, these are potential benefits, not guaranteed improvements.

Sebastian

AI coding agents also have important limitations. GitHub advises developers to review and test generated code because AI output may be incorrect or insecure. Agents may also misunderstand business requirements, miss edge cases, or suggest nonexistent software packages.

Evidence supports the need for human oversight. The Sonar State of Code survey reported that 95 percent of surveyed developers spend effort reviewing, testing, and correcting AI-generated code. It also reported that 38 percent said reviewing AI-generated code requires more effort than reviewing human-written code.

A Veracode analysis found that roughly 44 percent of its tested code-generation tasks introduced a vulnerability. This finding applies to Veracode’s specific tests and should not be generalized to every AI tool or programming task.

As agents become more common, developers may spend more time reviewing code, designing systems, testing edge cases, and making security decisions. Humans and organizations remain responsible for deciding whether generated changes are suitable for production.

Overall, AI coding agents can support developers, but they should be treated as assistants rather than replacements. Their value depends on the task, the available context, careful testing, and responsible human review. Thank you.
