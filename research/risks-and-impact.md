# AI Coding Agents: Risks, Limitations, and Impact on Developers

## Overview
This document outlines the security risks, reliability limitations, and long-term impact on developers associated with integrating AI coding agents into modern software engineering workflows.

---

## 1. Reliability & Security Risks

* **Hallucinations & Flawed Logic:** AI models often generate code that looks syntactically correct but contains subtle logic bugs, race conditions, or calls to non-existent packages/APIs (hallucinated dependencies).
* **Package Hallucination Attacks (Supply Chain Vulnerabilities):** Attackers actively publish malicious software packages matching common AI-hallucinated library names, tricking developers into downloading malware.
* **Security & Vulnerability Propagation:** AI models trained on public repositories frequently reproduce insecure coding patterns, such as hardcoded credentials, SQL injection vectors, and weak cryptographic practices.
* **Data Privacy & IP Leakage:** Uploading proprietary source code or sensitive API keys to third-party AI agent platforms poses severe intellectual property and compliance risks.

---

## 2. Why Human Review and Testing Remain Essential

* **Lack of Contextual Understanding:** AI agents evaluate code line-by-line or within prompt windows, but lack deep understanding of business logic, domain constraints, and system architecture.
* **Verification vs. Generation:** While AI can rapidly generate hundreds of lines of code, verifying correctness requires comprehensive automated testing (unit, integration, regression) and expert code review.
* **Accountability & Liability:** AI models cannot take responsibility for system failures, compliance breaches, or outage costs. The software engineer remains strictly accountable for code deployed to production.

---

## 3. Shifting Responsibilities for Developers

* **From Code Writers to Code Reviewers & Architects:** Developers spend less time writing boilerplate syntax and more time analyzing, validating, and refactoring agent-generated code.
* **Emphasis on System Architecture & Security:** Focus shifts toward high-level system design, threat modeling, API integration, and prompt engineering/orchestration.
* **Quality Assurance Emphasis:** Developers must develop stronger skill sets in unit testing, debugging, and edge-case scenario evaluation.

---

## 4. Supported Facts vs. Future Predictions

| Supported Facts (Current Evidence) | Future Predictions (Trends to Watch) |
| :--- | :--- |
| AI-generated code has higher rates of security vulnerabilities if unreviewed (OWASP / Security Benchmarks). | Coding agents will autonomously manage end-to-end pull requests and deployment pipelines. |

| Supply chain attacks via hallucinated packages are an active threat (ReversingLabs / Sonatype research). | Software maintenance costs will increase due to technical debt generated by unvetted AI code. |
